# Reproducibility

## Principles
- Use relative paths instead of personal/local paths.
- Record software versions where possible.
- Do not upload raw patient/cohort files.
- Document expected inputs and outputs.
- Keep sample metadata separate from sensitive information.
- Clearly distinguish original thesis analyses from later extensions.
