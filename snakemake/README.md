# Snakemake workflow

This directory contains a **reconstructed Snakemake workflow** based on the documented RNA-seq project methodology and the project record describing workflow automation with Nextflow and Snakemake.

## Intended workflow

FASTQ → QC → trimming → alignment → quantification → differential expression → downstream analysis

## Important note

The original Snakemake files were not retained. These files were recreated as a portfolio/reproducibility representation and are **not claimed to be the exact historical scripts**. Update the sample sheet, reference genome/index, GTF, software versions and parameters before execution.
